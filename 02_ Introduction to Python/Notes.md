## 1. Introduction to Python

### What is Python?

Python is a high-level, general-purpose programming language.
It was created by **Guido van Rossum** and released in **1991**.

Python is easy to learn and understand. Its syntax is very simple, almost like English, which makes it a great choice for beginners.

We can use Python for many different purposes like website making, data analysis, automation, machine learning, and more.

---

### Features of Python

Here are some important features of Python:

1. **Simple and easy to learn**
   Python code looks clean and is easy to write and read.

2. **Interpreted language**
   Python runs line by line. No need to compile the program before running it.

3. **Dynamically typed**
   You do not need to mention the type of variable. Python will understand it by itself.

4. **Cross-platform language**
   Python works on Windows, Linux, and Mac without any major changes in the code.

5. **Open source**
   Python is free to use. Anyone can download and use it.

6. **Large standard library**
   Python comes with many ready-made modules (libraries) which save time and effort.

7. **Supports object-oriented and functional programming**
   You can use classes and objects or write simple functions based on your need.

8. **Useful for both small and large projects**
   Python can be used for school-level projects as well as professional applications.

---

### Applications of Python

Python is used in many fields. Some of the common uses are:

* **Web development** (using Django, Flask)
* **Data analysis and data science** (using Pandas, NumPy)
* **Machine learning and artificial intelligence**
* **Game development**
* **Desktop applications** (using Tkinter)
* **Automation or scripting** (like sending emails, file handling)
* **Internet of Things (IoT)** projects with Raspberry Pi

### Installing Python and Setting Up IDEs

#### Step 1: Install Python

1. Visit the official website: [https://www.python.org](https://www.python.org)
2. Download the latest version of Python for your operating system (Windows, Mac, or Linux)
3. While installing, make sure to check the box that says **"Add Python to PATH"**
4. Click on **Install Now**

To check if Python is installed:

* Open your terminal or command prompt
* Type `python --version`
* It should show the installed Python version like `Python 3.12.0`

---

### Step 2: Install an IDE (Code Editor)

You can write Python code in many editors. Some of the popular ones are:

1. **VS Code (Visual Studio Code)**

   * Light-weight and easy to use
   * Good for beginners and advanced users
   * Download from: [https://code.visualstudio.com](https://code.visualstudio.com)

2. **PyCharm**

   * A smart editor with many features
   * Good for bigger Python projects
   * Download from: [https://www.jetbrains.com/pycharm](https://www.jetbrains.com/pycharm)

3. **Jupyter Notebook**

   * Used mostly in data science and machine learning
   * Allows you to run code in parts (cells) and add notes
   * To install:
     Open terminal and run:
     `pip install notebook`
     Then run:
     `jupyter notebook`
