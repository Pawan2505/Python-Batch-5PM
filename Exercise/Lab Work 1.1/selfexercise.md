### **Q.1 Who developed Python, and in which year was it first released?**

**Ans:** Python was developed by *Guido van Rossum* and was first released in the year *1991*.

---

### **Q.2 What are the major differences between Python 2 and Python 3?**

**Ans:** Python 2 is old and no longer maintained. Python 3 is the latest version with better syntax (like `print()` as a function), better Unicode support, and more powerful libraries.

---

### **Q.3 List some common use cases or applications of Python in various industries.**

**Ans:** Python is used in *web development, data science, artificial intelligence, automation, cybersecurity, game development,* and even *IoT projects*.

---

### **Q.4 What is the Python shell, and how is it used to execute Python commands?**

**Ans:** Python shell is like a *calculator for Python*. We type one line at a time and it shows the output instantly. Good for testing code quickly.

---

### **Q.5 Explain the difference between the Python shell and Python scripts.**

**Ans:** The shell runs one line at a time (interactive), while scripts are saved files (`.py`) where we can write multiple lines and run them all together.

---

### **Q.6 What is IDLE in Python, and how does it help in Python programming?**

**Ans:** IDLE is Python’s built-in editor. It helps us write, edit, and run programs easily, especially for beginners.

---

### **Q.7 Describe the use of the exit() command in the Python shell.**

**Ans:** The `exit()` command is used to *close the Python shell* when we're done using it.

---

### **Q.8 What are the alternatives to Python IDLE for writing Python programs?**

**Ans:** We can also use editors like *VS Code, PyCharm, Atom, Jupyter Notebook,* or even *online IDEs* like Replit.

---

### **Q.9 Explain the syntax rules you need to follow while writing a Python program.**

**Ans:** Use proper *indentation*, no semicolons, use `:` after `if`, `for`, etc., and follow naming rules for variables and functions.

---

### **Q.10 What are the two primary modes to run Python programs? Explain each.**

**Ans:**

* **Interactive Mode** – Code runs line by line in the shell.
* **Script Mode** – Code is saved in `.py` file and run as a full program.

---

### **Q.11 How do you run a Python program in Script Mode using the command line?**

**Ans:** Save your file as `program.py`, open command prompt, go to that folder, and type:

```bash
python program.py
```
